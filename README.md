# 'GNU' GREP written in Rust.

I wrote this `grep` implementation in Rust as my first major project after tutorials. It isn't very complex but it works. I plan to improve it and implement all the available flags (modeling it after GNU grep) and eventually add support for reading input just like the real `grep` does. Feel free to submit a patch or improve the code—it will help me grow as a developer. I wanna write a lot of gnu's staff but in future. I only used the Vim plugin in VS Code for this project, so sorry about the readability.
